
## 重启指令

### 1. 停止旧服务
```bash
# 先正常终止
kill 7606

# 等待3秒，如果进程还在就强制终止
sleep 3
if kill -0 7606 2>/dev/null; then 
    kill -9 7606
fi
```

### 2. 启动新服务
```bash
# 创建日志目录
mkdir -p logs/server

# 后台启动服务，设置Java环境变量
nohup env JAVA_HOME=/usr/lib/jvm/java-17-openjdk \
    PATH=/usr/lib/jvm/java-17-openjdk/bin:$PATH \
    PORT=8080 \
    ./scripts/start-maven-jetty.sh > logs/server/jetty.log 2>&1 &

# 保存进程ID
echo $! > logs/server/jetty.pid
```

## 使用的技术栈

### 1. **Java 17**
- 默认系统Java是1.8.0_492（Java 8）
- Jetty 12需要Java 17（class file version 61.0）
- 显式设置：`JAVA_HOME=/usr/lib/jvm/java-17-openjdk`

### 2. **Jetty 12.0.15**
- 使用EE10版本的Jetty Maven插件
- 启动命令：`mvn org.eclipse.jetty.ee10:jetty-ee10-maven-plugin:12.0.15:run`
- 端口：8080

### 3. **Maven 3.5.4**
- 项目管理工具
- 通过Maven插件启动Jetty嵌入式服务器

### 4. **启动脚本**
`start-maven-jetty.sh` 内容：
```bash
#!/usr/bin/env bash
SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
RELEASE_DIR="$(cd "${SCRIPT_DIR}/.." && pwd)"
PORT="${PORT:-8080}"

export RECRUITASSIST_BASE_DIR="${RELEASE_DIR}"

exec mvn -f "${RELEASE_DIR}/framework/recruitassist-web/pom.xml" \
  org.eclipse.jetty.ee10:jetty-ee10-maven-plugin:12.0.15:run \
  -Djetty.http.port="${PORT}"
```

## 关键技术点

### 1. **版本兼容性**
- Jetty 12需要Java 17+，但系统默认是Java 8
- 必须显式设置Java环境变量才能启动

### 2. **后台运行**
- 使用`nohup`和`&`实现后台运行
- 日志重定向到`logs/server/jetty.log`
- 进程ID保存到`logs/server/jetty.pid`

### 3. **健康检查**
- 服务启动后通过`/health`端点验证
- 返回JSON状态：`{"status":"UP","users":99,"jobs":67,"applications":965}`

### 4. **访问地址**
- 本机测试：`http://127.0.0.1:8080/home`
- 外部访问：`http://RecruitAssistGroup38.21.214.216.122.nip.io:8080/home`

这次重启主要解决了Java版本兼容性问题，确保Jetty 12能在Java 17环境下正常运行。
